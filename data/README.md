# Dataset

## Overview

This folder contains the synthetic dataset used for the Workforce Case Volume & Staffing Forecast Analysis project.

The dataset was created specifically for portfolio and demonstration purposes. It simulates historical case-volume and investigator-assignment data that can be used to demonstrate data cleaning, workload analysis, trend analysis, and forecasting techniques.

## Data Privacy

The dataset contained in this repository is entirely synthetic.

It does not contain confidential case records, employee names, investigator names or initials, original case identifiers, personally identifiable information (PII), or other organizational records.

Synthetic investigator identifiers such as `INV-01`, `INV-02`, and `INV-03` are used in place of real individuals.

Synthetic case identifiers are also used throughout the dataset.

## Dataset Fields

| Field | Description |
|---|---|
| Case_ID | Artificial identifier assigned to each synthetic case |
| Received_Date | Synthetic date representing when the case was received |
| Year | Calendar year associated with the case |
| Month | Month in which the case was received |
| Investigator_Assignment | Synthetic investigator ID(s) assigned to the case |
| Data_Type | Identifies the records as synthetic data |

## Dataset Use

The dataset is used to demonstrate:

- Data cleaning and transformation
- Excel analysis
- Power Query
- PivotTables
- Annual and monthly trend analysis
- Investigator workload analysis
- Linear regression
- Case-volume forecasting
- Data visualization
- Workforce planning and business analysis

## Important Note

The synthetic dataset was designed to reproduce a realistic workforce analytics scenario. Any trends, investigator assignments, dates, and case-level records contained in the dataset are provided solely for demonstration purposes and should not be interpreted as actual organizational records.
